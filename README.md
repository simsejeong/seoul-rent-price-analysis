## 1. 분석 배경

이사를 준비하며 특정 지역을 먼저 정하기보다 **예산과 주거 조건에 맞는 지역**을 찾고자 했습니다.
부동산 플랫폼에서도 시세 조회는 가능하지만, 서울 지역에 대한 사전 정보가 부족하면 여러 지역의 시세와 매물 조건을 하나씩 비교해야 했습니다.

| 질문 | 분석 |
|---|---|
| Q1. 내 예산과 주거 조건에 맞는 지역은 어디인가? | 예산 적합성 평가 |
| Q2. 지역·면적·건물 연식에 따라 가격은 어떻게 달라지는가? | 가격 구조 분석 |
| Q3. 내 조건에서 전세와 월세 중 어떤 선택이 더 현실적인가? | 2년 실주거비 비교 |
| Q4. 예측가격보다 저렴하게 거래된 사례가 많은 지역은 어디인가? | 저평가 거래 탐색 |

## 2. 데이터와 전처리

| 항목 | 내용 |
|---|---|
| 출처 | 국토교통부 실거래가 공개시스템 (서울, 2023~2025) |
| 주택유형 | 아파트 · 오피스텔 · 연립다세대 · 단독다가구 |
| 규모 | 원천 약 193만 건 → 정제 후 약 181만 건 |
| 범위 | 25개 자치구 · 405개 구-법정동 조합 |

**전처리**
1. 건축연도 1900~2025년 범위 외 제거
2. 면적당 보증금·월세 상위 1% 이상치 제거
3. 전용면적 10~200㎡로 분석 대상 제한
4. 임대 유형 재분류 — 전월세구분이 '월세'라도 월세 5만 원 이하면 준전세
5. 행정동 좌표를 법정동 단위로 평균해 결합 (거래 복제 방지 검증 포함)
6. 면적·층·연식 구간화, 강남역 거리 등 분석 변수 생성

> **환산월세** = 월세 + 보증금 ÷ 100 (보증금 100만 원을 월세 1만 원으로 환산, 지역·유형 간 가격 비교용 지표)

## 3. 가격 구조 분석

- **주택유형별 임대 구조**: 아파트는 전세(56.9%), 오피스텔·단독다가구는 준전세 비중이 가장 높음
- **지역별 가격 격차**: 자치구별 평(3.3㎡)당 환산월세 중앙값은 강남구 20.2만 원, 강북구 8.2만 원으로 약 2.5배 차이
- **면적**: 면적이 클수록 환산월세가 상승 (초소형 평균 70만 원 → 초대형 618만 원)
- **건물 연식**: 중간 연식(15~29년)의 중앙값이 신축보다 높음 → 면적·입지 등 다른 특성의 영향이 함께 작용

→ 단일 요인으로는 가격 차이를 설명하기 어려워, 주택·지역 특성을 함께 고려한 예측 모델이 필요

## 4. 가격 예측 모델링

- 예측 대상: 월세 · 월세 보증금 · 전세 보증금 (로그 변환 후 학습)
- 입력 변수: 구 · 동 · 위경도 · 강남역 거리 · 강남 3구 여부 · 면적 · 층 · 건물 연식 · 주택유형
- 검증: 학습:검증 = 8:2, 원 단위로 복원해 평가

| 예측 대상 | 선형회귀 R² | **LightGBM R²** | LightGBM MAE |
|---|---:|---:|---:|
| 월세 | 0.38 | **0.54** | 31.9만 원 |
| 월세 보증금 | 0.25 | **0.48** | 6,878만 원 |
| 전세 보증금 | 0.65 | **0.89** | 5,935만 원 |

**변수 중요도** (LightGBM, Gain 기준)

| 구분 | 1위 | 2위 | 3위 | 위치 변수 합계 |
|---|---|---|---|---:|
| 월세 | 면적 53.9% | 동 28.7% | 주택유형 7.7% | 32.4% |
| 전세 | 주택유형 70.9% | 면적 13.4% | 동 5.4% | 6.5% |

## 5. 저평가 거래 탐색

- **잔차** = 실제 거래가격 − 예측가격
- 저평가 거래 후보: 잔차 < 0 이면서 예측가격 < 서울 평균 예측가격
- 법정동별 저평가 거래 후보 비중을 집계해 (전월세별 거래 20건 이상) 거주 지역 탐색 우선순위로 활용
- 상위 지역 예시 — 전세: 강서구 외발산동 85% · 종로구 관철동 81% · 중구 무학동 76% / 월세: 종로구 관철동 88% · 영등포구 문래동1가 71%

## 6. Power BI 대시보드

| 페이지 | 내용 |
|---|---|
| 1. 월세 시장 탐색 | 지역·주택 조건별 월세 시세, 월세 거래 및 저평가 후보 분포, 평균 월세·보증금 |
| 2. 전세 시장 탐색 | 지역·주택 조건별 전세 시세, 전세 거래 및 저평가 후보 분포, 평균 전세보증금 |
| 3. 지역 추천 · 가격 비교 | 지역별 전월세 가격 비교, 저평가 거래 후보 비중 Top 5, 지역별 면적·층·가격 특성 |
| 4. 예산 시뮬레이션 | 예산·주거 조건별 예상 가격, 전월세 예산 적합성 판단, 2년 실주거비 비교 |

**예산 시뮬레이션 예시** — 노원구 공릉동 · 보증금 1억 · 월세 70만 원 · 중소형 아파트 · 중층

| 항목 | 결과 |
|---|---|
| 예상 월세 / 월세보증금 / 전세보증금 | 64만 원 / 6,331만 원 / 3.11억 원 |
| 월세 가능 여부 · 전세 가능 여부 | 가능 · 어려움 |
| 2년 실주거비 (보증금 기회비용 연 4%) | 월세 2,043만 원 · 전세 2,488만 원 |
| 추천 전략 | **월세 추천** |

> 판단 로직: 예산 충족 여부를 우선 확인하고, 둘 다 가능하면 2년 실주거비(월세 24개월분 + 보증금 기회비용)를 비교합니다.
> 예측가격 기준 판단이므로 실제 매물 가격 및 계약 가능 여부와 차이가 있을 수 있습니다.

## 7. 폴더 구조와 실행 방법

```
seoul-rent-price-analysis/
├── README.md

│   └── seoul_rent_analysis.ipynb   # 정제 · EDA · 좌표 결합 · 모델링 · 대시보드용 CSV 저장
```

1. [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/)에서 서울 전월세 실거래 CSV(주택유형 4종 × 2023~2025)를 내려받아 `data/`에 저장

3. 노트북 실행 → `data/processed/`에 Power BI용 CSV 생성
